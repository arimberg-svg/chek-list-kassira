# Введение в должность кассира

12–15 ноября 2026 кассир работает с предыдущим кассиром: смена, поиск товара, доппродажи, кредит и инкассация. 16–20 ноября смену смотрит СПК: документы, стол заказов, монитор интернет-магазина и юридические лица.

## Откуда операции

- Чек-лист наставника СПК: неделя с кассиром в схеме на 3 недели и неделя кассира в архиве 5+1
- Обучение кассира, блоки от открытия смены до промокодов
- Действующие правила: вечерний отчёт в 1С, лимит кассы с 21 января 2026, Сберинкассация, возврат, продажа когда касса не работает, добор товара, семь точек на кассе
